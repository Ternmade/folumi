# Folumi — public site

Product presentation, support and privacy for Folumi 0.1, available on iOS.
English and Portuguese: https://ternmade.github.io/folumi/.

Generated from the product workspace with `scripts/build-local-pages.py`:
`site/` owns presentation; `apps/mobile/assets/legal/local_release.json` owns
support and privacy. Do not edit generated HTML here. Publish only the static
output, without `--preview`, using `Ternmade <ternmade@outlook.com>`.

The existing support and privacy URLs are preserved. No analytics, forms or
health-data collection were added. `sitemap.xml` lists the canonical pages;
host-level crawler instructions are at `https://ternmade.github.io/robots.txt`.
Being crawlable is not proof of indexing. Updated 25 October 2026.
